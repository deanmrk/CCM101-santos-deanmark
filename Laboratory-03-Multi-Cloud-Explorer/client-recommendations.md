# Client Recommendations

## Client A – Startup
**Recommended:** AWS  
AWS is ideal for startups due to its pay-as-you-go pricing and scalability. It allows businesses to grow without large upfront costs.  
Services: EC2, S3, Lambda  

## Client B – University college
**Recommended:** Microsoft Azure  
Azure integrates well with Microsoft tools already used by the university. It simplifies migration and management.  
Services: Azure VM, Azure AD, Blob Storage  

## Client C – AI Company
**Recommended:** Google Cloud Platform  
GCP provides strong AI and ML tools with high-performance computing.  
Services: AI Platform, Compute Engine, BigQuery  

## Client D – E-Commerce
**Recommended:** AWS  
AWS offers global infrastructure and auto-scaling for high traffic.  
Services: EC2, Auto Scaling, CloudFront


## Decision Matrix

| Requirement | Platform | Justification |
|------------|---------|--------------|
| Startup | AWS | Low cost and scalable |
| Enterprise | AWS | Wide services |
| Microsoft Environment | Azure | Best integration |
| AI/ML | GCP | Strong AI tools |
| Kubernetes | GCP | Native support |
| Global App | AWS | Global infrastructure |
