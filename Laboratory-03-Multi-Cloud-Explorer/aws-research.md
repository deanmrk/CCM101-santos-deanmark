# Amazon Web Services (AWS) Research

## Overview
Amazon Web Services (AWS) is a cloud computing platform launched by Amazon in 2006. It provides a wide range of services including computing power, storage, and networking.

## Global Infrastructure
AWS has multiple Regions and Availability Zones worldwide, ensuring high availability and fault tolerance.

## Cloud Management Console
AWS uses a web-based dashboard called the AWS Management Console to manage services.

## Core Services
- EC2 (Elastic Compute Cloud) – Virtual servers
- S3 (Simple Storage Service) – Object storage
- RDS (Relational Database Service) – Managed database
- VPC (Virtual Private Cloud) – Networking

## Advantages
- Wide range of services
- Highly scalable
- Strong global infrastructure

## Use Cases
- Web hosting
- Application development
- Big data processing
