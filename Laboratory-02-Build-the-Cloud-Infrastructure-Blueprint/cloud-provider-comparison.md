# Cloud Provider Comparison

| Infrastructure | AWS | Azure                  | GCP            |
|--------------- |-----|------------------------|----------------|
| Compute        | EC2 | Virtual Machines       | Compute Engine |
| Storage        | S3  | Blob Storage           | Cloud Storage  |
| Networking     | VPC | Virtual Network        | VPC            |
| IAM            | IAM | Azure Active Directory | Cloud IAM      |

Questions:

1. Broadest services
AWS offers the widest range of services because it has been in the market longer and provides many tools for different needs.

2. Microsoft users
Azure is best because it integrates well with Microsoft products like Windows and Office.

3. AI & ML
GCP is known for AI, ML, and Kubernetes because of Google’s expertise in these areas.

4. Similarities
All providers offer compute, storage, networking, and IAM services with different names but same functions.
