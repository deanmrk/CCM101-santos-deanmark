# Cloud Infrastructure Components

## Compute Resources
CPU and cores process tasks and run applications.
This is important because cloud systems need computing power.
In KillerCoda Ubuntu, the CPU shown in lscpu represents compute.

## Storage Resources
Storage holds files and data.
Important for saving applications and databases.
In KillerCoda, disk shown in df -h is storage.

## Networking Resources
Networking connects systems using IP addresses.
Important for communication in cloud.
In KillerCoda Ubuntu, IP from ip a shows networking.

## Operating System
Linux manages hardware and software resources.
Important because cloud servers run on OS.
KillerCoda uses Linux (Ubuntu).
