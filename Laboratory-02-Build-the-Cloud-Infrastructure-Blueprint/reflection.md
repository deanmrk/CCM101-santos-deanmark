# Mission Reflection

In this activity, I learned about different components of cloud infrastructure such as compute, storage, networking, and operating systems. For me, the most important component is compute resources because it is responsible for processing all tasks and running applications. Without CPU and processing power, nothing in the system will work. It is like the “brain” of the cloud system, so it plays a very important role.

Linux supports cloud computing by providing a stable and efficient operating system that manages hardware resources. It allows users to run commands, manage files, and control system processes easily. Many cloud servers use Linux because it is lightweight, secure, and reliable. During this activity, I was able to explore Linux commands, which helped me understand how cloud environments actually work behind the scenes.

Technical documentation is very important before deploying infrastructure because it helps engineers plan everything properly. It ensures that all components are organized and understood before implementation. Without documentation, it would be difficult to troubleshoot problems or maintain the system in the future. It also helps teams communicate clearly about the system design.

In this laboratory activity, I learned new skills such as using Linux commands, analyzing system information, creating Markdown documentation, and understanding cloud service providers. I also improved my ability to explain technical concepts in a simple way.

After completing this mission, my GitHub portfolio improved because it now contains organized documentation, structured files, and clear outputs of my work. It shows my progress and understanding of cloud computing concepts, which can be useful for future projects and career opportunities. Thank you ma'am!
