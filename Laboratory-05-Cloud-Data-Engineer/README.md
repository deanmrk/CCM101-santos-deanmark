# Laboratory 5: Cloud Data Engineer

## Mission Overview
For this laboratory, it focuses on deploying an object storage system using MinIO. My goal is to simulate a real world cloud storage setup for storing large amounts of unstructured data such as images.

## The Objectives
- Understand different types of cloud storage
- Deploy an object storage server using Docker
- Access cloud services through a web interface
- Create buckets and upload files
- Document cloud deployment processes

## The Tools i Used
- Docker
- MinIO
- GitHub
- KillerCoda Playground
- Web Browser (Brave)

## The Skills i Learned
- Container deployment using Docker
- Cloud storage concepts
- Object storage management
- Documentation using Markdown
