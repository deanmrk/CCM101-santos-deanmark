# Cloud Storage Types Comparison

| Storage Type   | Description                                                                 | Primary Use Case                                  | Cloud Example |
|----------------|-----------------------------------------------------------------------------|--------------------------------------------------|---------------|
| Block Storage  | Stores data in fixed-size blocks like a hard drive                         | OS, databases, virtual machines                  | AWS EBS       |
| File Storage   | Stores data in files and folders with hierarchy                            | Shared drives, file servers                      | AWS EFS       |
| Object Storage | Stores data as objects with metadata and unique IDs                        | Images, videos, backups, cloud apps              | AWS S3        |

## Why Object Storage?

For me, as an it. The Object storage is like ideal for storing millions of users uploaded images because it is highly scalable and i think can handle large volumes of unstructured data. It allows easy access through the web and provides metadata for better organization. This makes it more efficient compared to block and file storage.
