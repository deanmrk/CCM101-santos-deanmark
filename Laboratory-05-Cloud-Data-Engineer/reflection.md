# My Mission Reflection

As an it student, for me the object storage is better suited for storing millions of photos and compared to traditional block storage because it is designed for scalability and handling unstructured data. Unlike block storage, which is limited and requires manual management, object storage allows easy storage and retrieval of large files over the internet. It also includes metadata, making files easier to organize and manage.

Using Docker made it easier to deploy the MinIO storage server because it eliminated the need for complex manual installation. With just one command, the entire server was set up and running. Docker ensures consistency, meaning the application works the same way across different systems.

A bucket in cloud storage is like a container or folder where files are stored. It helps organize data and allows users to manage access and permissions easily. In this activity, the bucket named "client-photos" was used to store uploaded files.

Large enterprise companies ensure their data is not lost by using redundancy and replication. This means they store copies of data in multiple locations or servers. If one server fails, the data can still be accessed from another backup location. They also use automated backup systems and cloud disaster recovery solutions.

My confidence in navigating the Linux command line is improving. At first, it was confusing, but through practice and repeated use of commands, I am becoming more comfortable. I can now run containers, check running processes, and understand basic commands more efficiently in github. Thank you!!
